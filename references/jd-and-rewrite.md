# JD Mapping and Evidence-Safe Rewriting

## Parse the job description

Classify each requirement as:

- must-have
- preferred
- core responsibility
- domain or deployment context
- seniority and ownership expectation

Create stable requirement IDs. Link each requirement only to ledger claim IDs.

Assign:

- DEMONSTRATED: Directly supported by strong claims
- TRANSFERABLE: Adjacent evidence with an explainable bridge
- UNSUPPORTED_MENTION: Keyword exists without defensible experience
- GAP: Relevant evidence is absent
- UNKNOWN: Input is insufficient

Treat ATS compatibility and keyword match as estimates, not guarantees. Never recommend a keyword the candidate cannot defend.

## Build the application strategy

Prioritize:

1. Must-have gaps that can determine screening
2. Highest-value projects for this JD
3. Evidence that supports target seniority
4. Terminology alignment using truthful synonyms
5. Parseability and section hierarchy

Do not hide genuine gaps with wording. Distinguish a document gap from a capability gap.

## Rewrite from the ledger

For each rewrite:

1. Preserve the exact fact pattern.
2. Lead with the candidate's action and decision.
3. Name the problem or constraint.
4. Explain the differentiating mechanism.
5. Add scale or outcome only from supported ledger fields.
6. Remove redundant Agent nouns.
7. Keep one primary idea per bullet.

Prefer:

~~~text
Action + mechanism + constraint or rationale + measured result
~~~

Use explicit placeholders such as [N tasks], [baseline], [latency], or [candidate to verify] for missing facts. Link every placeholder to missing_evidence in the claim.

Never:

- Upgrade ownership during rewriting
- Turn team output into personal output
- Convert a reasonable architecture inference into a fact
- Invent framework names, metrics, users, scale, or production status
- Let a rewritten claim receive a higher evidence status without new evidence

## Output targeted changes

Show:

- original text and claim IDs
- diagnosis
- proposed wording
- retained evidence status
- facts requiring confirmation

Provide a full rewritten resume only when requested. Otherwise rewrite the highest-priority bullets and recommend project order.
